diy-ui · A/B 两种 API 对照

A = app.div("")（providers/dom.ts，eager / 命令式，最小更新单位是「重跑整块」） 　·　B = yield html.div()（providers/dom-gen.ts，pull / Spec，重跑 + keyed 对账）

Counter 信号 → 界面

A · app.column().cell(() => app.label(...)) —— 每次重跑清空重建这一列
B · text: () => ... —— 重跑块只建结构，文本走 getter 原子更新

Reactive 多信号 + 历史列表

A · 两个 cell（历史 / 状态）各自重建
B · 一个重跑块；历史 keyed 只追加、状态走 getter

Generator 步进 yield 到底能不能「一条一条出」

A · cell(function* (n) {{ yield n.label(...) }}) —— 同步 generator 同样一轮 drain（要逐步得用 cell(async …)）
B · children 生成器同步 drain（三步同时出现）；要逐步必须 mountStream

异步并发 三路任务互不干扰

A · cell(async function* (n) {{ await …; n.label(…) }}) —— 重跑整块重建
B · mountStream(node, source, …) —— 0 重跑，历史行保留

流式消息 append-only

A · 没有增量入口：cell 重跑 → 每来一条**清空整列重建**
B · mountStream：每条一条 insert，0 重跑 0 查表
