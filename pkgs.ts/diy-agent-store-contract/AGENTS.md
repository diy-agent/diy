# @diy-agent/store-contract — 存储契约测试（只有测试工具）

> 全仓契约见**仓库根 `AGENTS.md`**。本包**没有生产代码**，只有两个 `define*Contract` 函数
> （`./session` / `./bot` 子路径分别引），由各实现在自己的 `tests/` 里调用。

## 一句话

「同一接口的多个实现行为是否一致」由**同一批用例**自动暴露，不再靠人肉比对两份 intent 测试（##506）。

## 硬约束

1. **这里只放测试工具**：不许有生产代码 / 不许被运行时 import（只允许 `devDependency`）。
2. **只测接口语义**：实现特有的行为（切桶 / 容量上限 / 落盘形状 / 读兼容）属于各实现自己的
   `intent.*.test.ts`，**不进契约** —— 塞进来会让另一个实现为了过契约而被迫模仿它。
3. 用例必须对**同步实现和异步实现都成立**：内存 store 的方法是同步的（同步 throw），
   断言一律经 `await` 归一（见 `src/session.ts` 的 `codeOf`）。
4. 不改任何 store 的实现。契约红了 = 实现跑偏了，不是改契约迁就它。
