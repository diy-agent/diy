
## dev React 界面 vs 老界面：功能缺口清单（2026-11-10，逐函数对照）

对照方式：`git show HEAD~1:pkgs/dev-page/src/renderer.ts`（1147 行）里的 41 个函数 → 新版 `apps/dev/src-ui/**`。

| # | 老功能（函数 / 交互） | 新版状态 |
|---|---|---|
| 1 | **交叉表** `renderTreeCross`：行=worktree/分支、列=app、格子=launch；分支色相 `columnLightness` | ❌ 现在是「按 worktree 分组的列表」 |
| 2 | **按仓库分组 + 可折叠**（`collapsedRepos` 持久化） | ❌ 没有仓库层 |
| 3 | **「只显示运行中」过滤**（`onlyRunning` 持久化 + aria-pressed） | ❌ 没有 |
| 4 | **外部实例** `renderExternals` / `renderExternalDetail`（真生产 / 孤儿，只读、无停止按钮） | ❌ 完全没渲染 |
| 5 | **worktree 详情页** `renderWorktreeDetail`（点分支名进入，内部 info/files/ref 页签 + 持久化 `wtPanes`） | ❌ 只有 launch 详情 |
| 6 | **entries 卡**：每个 web 入口的 URL、实际端口 vs 配置端口不一致提示 | ❌ 没有 |
| 7 | **instances 卡**：同一 launch 多份实例逐条列出（各自聚焦/停止） | ⚠️ 只在侧栏显示名字，无操作 |
| 8 | **URI 卡 + 复制**（`diy://node/app.launch`，`copyText` + toast） | ❌ 没有 |
| 9 | **params 卡**：app.yaml 声明的 env | ❌ 没有 |
| 10 | **runtime 卡**：uptime / 常驻内存 / 命令行 / cwd / 数据根 | ⚠️ 只有 slot 贡献的 uptime + 内存 |
| 11 | **build 卡**：build / check / test / sync / build-pkgs / clean 六个按钮 + 输出 | ❌ 没有（`DEV_METHODS.run` 未接） |
| 12 | **重启** `restartLaunch`（stop → start） | ❌ 没有 |
| 13 | **打开 CDP**（`revealCdp`，打印 ws 地址并复制） | ❌ 没有 |
| 14 | **打开目录三模式**：Finder / VS Code / 终端（`openDir(which, mode)`） | ⚠️ 只有 editor |
| 15 | **复制 PID**（toast 反馈） | ❌ 没有 |
| 16 | **分栏可拖拽 + 宽度持久化**（workbench-ui `createSplitPane`，`splitWidth`） | ❌ 固定 260–340px |
| 17 | **toast**（操作反馈：已启动/已复制/报错） | ❌ 只有状态栏最后一行 |
| 18 | **顶部统计**：运行中数量、仓库名、变体 | ⚠️ 只有每行分支名 |
| 19 | **清空命令输出**（`clearSession`） | ❌ 没有 |

已有且对齐的：启动/停止/聚焦、launch 选中、命令输出（启动日志）、文件页签（树 + 编辑器 + 保存）、外部仓库页签（列表/添加/移除/同步/打开）、运行中实例名字展示。

结论：**不是小缺口，是「详情面板 8 张卡 + 交叉表 + 外部实例 + 分栏」整片没迁**。按价值排：
P0 外部实例（生产可见性）、build 卡（日常最常用）、entries/instances/uri/params/runtime 卡、打开目录三模式、重启、清空输出；
P1 交叉表 + 仓库折叠 + 只显示运行中 + 持久化；
P2 分栏拖拽 + toast + 顶部统计。
